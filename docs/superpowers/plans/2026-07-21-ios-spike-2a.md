# iOS Fizibilite Kanıtı (2a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apple Developer hesabı veya fiziksel Mac olmadan, tamamen ücretsiz GitHub Actions CI ile, Kuaförüm'ün gerçek Compose Multiplatform kodunun ve Supabase-kt ağ katmanının iOS Simulator runtime'ında fiilen çalıştığını otomatik testlerle kanıtlamak.

**Architecture:** Mevcut `:app` (canlı Android uygulaması) dokunulmadan, yeni bir `:composeApp` Kotlin Multiplatform modülü eklenir (`commonMain`/`androidMain`/`iosMain`/`commonTest`). Kanıt, gerçek bir Xcode projesi/ekran görüntüsü yerine, Compose Multiplatform'un resmi `runComposeUiTest` API'si (Compose'un iOS'ta gerçekten render olduğunu kanıtlar) ve düz bir coroutine testinin (Supabase-kt'nin iOS'ta gerçek ağ çağrısı yaptığını kanıtlar) `iosSimulatorArm64Test` Gradle görevi üzerinden CI'da çalıştırılmasıyla sağlanır. Bu, hiç Xcode/Mac gerektirmeyen, Kotlin/Native'in resmi olarak desteklediği bir test yoludur.

**Tech Stack:** Kotlin Multiplatform 2.2.10, Compose Multiplatform (~1.8.0), Supabase-kt 3.0.1 (Postgrest + Auth), Ktor 3.0.1 (okhttp/darwin motorları), kotlinx-coroutines-test, GitHub Actions (`macos-14` runner).

## Global Constraints

- İzolasyon: Tüm değişiklikler `ios-spike` branch'inde yapılır; `main` (canlı Android uygulaması) hiç değiştirilmez. [Spec: "İzolasyon"]
- Sunucu-otoriter model: Bu spike'ta "DB okuması" Supabase Postgrest üzerinden yapılır, Room üzerinden DEĞİL — Room'un cache-only rolüne indirgenmesi kararı gereği, Room/SQLDelight kararı bilinçli olarak alt proje 3'e ertelenmiştir. [Spec: "Veri Katmanı: Sunucu-Otoriter Model"]
- `service_role` anahtarı bu spike'ta hiç kullanılmaz — yalnızca `anon key` ile Postgrest okuması yapılır (anon key zaten public tasarımlıdır). [Spec: "Güvenlik Mimarisi", madde 2-3]
- CI: Yalnızca GitHub Actions `macos-14` runner kullanılır (public repo → ücretsiz, sınırsız dakika); Codemagic/Fastlane bu aşamada devreye girmez. [Spec: "CI / Dağıtım Stratejisi"]
- Başarı kanıtı iddiayla değil, CI artifact'i (test-results XML + stdout log) ile sağlanır. [Spec: "Go/No-Go Kapıları"]
- **Kapsam sapması (şeffaf not):** Spec metni "screenshot artifact" diyordu; bu plan bunun yerine `runComposeUiTest` tabanlı otomatik render testi + coroutine tabanlı canlı ağ testi kullanıyor. Gerekçe: hand-crafted bir Xcode `.xcodeproj` dosyasını Mac/Xcode hiç kullanmadan güvenilir şekilde yazmak yüksek risktir ve CI'da kırılgandır; oysa `runComposeUiTest` + düz coroutine testi, Compose Multiplatform'un resmi ve CI-dostu test yoludur, aynı riski (Compose iOS'ta gerçekten çalışıyor mu, Supabase-kt iOS'ta gerçekten ağ çağrısı yapıyor mu) daha güvenilir şekilde kanıtlar. Bu karar Halil'e sunum sırasında ayrıca açıklanacaktır.

```kotlin
import org.jetbrains.kotlin.gradle.ExperimentalKotlinGradlePluginApi
import org.jetbrains.kotlin.gradle.dsl.JvmTarget

plugins {
    alias(libs.plugins.kotlin.multiplatform)
    alias(libs.plugins.compose.multiplatform)
    alias(libs.plugins.kotlin.compose)
    alias(libs.plugins.android.library)
}

kotlin {
    androidTarget {
        @OptIn(ExperimentalKotlinGradlePluginApi::class)
        compilerOptions {
            jvmTarget.set(JvmTarget.JVM_11)
        }
    }

    listOf(
        iosX64(),
        iosArm64(),
        iosSimulatorArm64()
    ).forEach { iosTarget ->
        iosTarget.binaries.framework {
            baseName = "ComposeApp"
            isStatic = true
        }
    }

    sourceSets {
        commonMain.dependencies {
            implementation(compose.runtime)
            implementation(compose.foundation)
            implementation(compose.material3)
            implementation(compose.ui)
        }
        commonTest.dependencies {
            implementation(kotlin("test"))
            implementation(libs.kotlinx.coroutines.test)
            implementation(compose.uiTest)
        }
        androidMain.dependencies {
            implementation(libs.androidx.activity.compose)
        }
    }
}

android {
    namespace = "com.example.composeapp"
    compileSdk = 35
    defaultConfig {
        minSdk = 21
    }
    compileOptions {
        sourceCompatibility = JavaVersion.VERSION_11
        targetCompatibility = JavaVersion.VERSION_11
    }
}

tasks.withType<AbstractTestTask> {
    testLogging {
        showStandardStreams = true
        events("passed", "skipped", "failed", "standardOut", "standardError")
    }
}
```

- [ ] **Step 2: `SupabaseSpike.kt` içinde canlı doğrulama fonksiyonunu yaz**

```kotlin
package com.example.composeapp

import io.github.jan.supabase.auth.Auth
import io.github.jan.supabase.auth.auth
import io.github.jan.supabase.auth.providers.builtin.Email
import io.github.jan.supabase.createSupabaseClient
import io.github.jan.supabase.postgrest.Postgrest
import io.github.jan.supabase.postgrest.postgrest
import kotlinx.serialization.json.JsonObject

object SpikeSupabaseClient {
    val client = createSupabaseClient(
        supabaseUrl = SpikeConfig.SUPABASE_URL,
        supabaseKey = SpikeConfig.SUPABASE_ANON_KEY
    ) {
        install(Postgrest)
        install(Auth)
    }
}

suspend fun runLiveAuthAndDbCheck(email: String, password: String, table: String): String {
    return try {
        SpikeSupabaseClient.client.auth.signInWith(Email) {
            this.email = email
            this.password = password
        }
        val rows = SpikeSupabaseClient.client.postgrest[table].select().decodeList<JsonObject>()
        "OK: login başarılı, '$table' tablosundan ${rows.size} satır okundu"
    } catch (e: Exception) {
        "FAIL: ${e.message}"
    }
}
```
